# Contributing to AlliedDefenses

Thanks for your interest in the mod! Please read this before contributing.

## Bug reports and problems — welcome (issues only)

The **only** accepted contribution is **reporting bugs or problems** via GitHub **issues**.

When you open an issue, please include:
- what happened vs. what you expected,
- **where** the problem is (which command, upgrade, enemy, or situation),
- whether you were **solo or in multiplayer** (and if everyone had the mod, same version),
- the relevant part of your **BepInEx log** if there's an error,
- your mod version (e.g. `0.13.0`).

I read every issue and fix problems on my side.

## Code contributions — not accepted

**Pull requests are disabled** on this repository and **code contributions are not accepted.**
Please do not submit code changes, forks distributed as releases, or modified versions.

This is intentional: the mod is developed and maintained solely by its author. See the
[LICENSE](LICENSE) — all rights are reserved.

## Anything else

To request permission for anything not covered above, contact the author through the GitHub
repository. Thanks for understanding!
